# Лекция «Шаблоны, часть 1» — примеры

Каждая папка — отдельный пример со своим Makefile.

    make        # собрать
    make run    # собрать и запустить
    make clean

Цели error-* компилируют код с ожидаемой ошибкой и показывают сообщение компилятора.
Требуется g++ с поддержкой C++17; для 21_binary_growth и 22_extern_template — python3 и bc,
для make icf — ld.gold.
